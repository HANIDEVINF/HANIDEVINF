## Featured projects

### [MuCAT — Multilingual Transformer](https://github.com/HANIDEVINF/MUCAT-Multilingual-Transformer)
A research implementation combining an mDeBERTa-v3 backbone with hierarchical attention pooling, language-aware FiLM conditioning, an evidential Dirichlet head, and an auxiliary script head. The repository documents the dataset, baselines, label-mapping correction, and reported results. The reported benchmark should be interpreted alongside the experiment protocol and limitations in the README.

### [ECG Arrhythmia Classification v7](https://github.com/HANIDEVINF/deep-learning-model-for-anomaly-detection-of-ECG)
A 1D-CNN + Transformer ECG classifier evaluated using a patient-wise MIT-BIH DS1/DS2 split, with an INT8 TFLite export. The repository reports a 90.13% ensemble accuracy and 0.529 macro-F1; minority-class sensitivity remains a key limitation and is documented in the results.

### [LLM Evaluation Framework](https://github.com/HANIDEVINF/llm-evaluation-framework)
An evolving project for comparing LLM application behavior and documenting evaluation criteria. Check the repository README for the currently implemented functionality and reproduction steps.

### [MedGuardAI](https://github.com/HANIDEVINF/MED-Guard-AI.)
An academic capstone exploring medical IoT monitoring and telehealth integration. See the repository for the implementation scope and project context.
